# 🎮 C++ Tic Tac Toe Game

A two-player console based Tic Tac Toe game developed using C++.

## ✨ Features
- **Two Player Game:** It’s a game between player 'X' and player 'O'.
- **Results Storage:** The game results can be stored in `Result.txt` file using C++ File I/O.
- **Validation of Input:** Verifies the input position is not already filled with another player input.

## 🛠️ Concepts Involved
- C++ Basic Programming Concepts (`iostream`, `fstream`)
- 2-D array and array pointers
- Function and loops
- File Handling (Store and retrieve scores)
